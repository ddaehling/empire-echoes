## Practical limits

The 45-minute allocation is a desk-based estimate, not a classroom pilot. Allow adaptations for reading speed and support needs, and protect the final twelve minutes. External source links need internet; the labelled summaries, atlas, photographs and written work function locally. Historical coverage is approximated with modern geographic units, and the interface explains uncertainty and year-end snapshots. Written work requires teacher judgement; word counts only verify completeness.
